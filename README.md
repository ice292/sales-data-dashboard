# รายงานข้อมูลการขาย (Sales Data Dashboard)

🔗 **Live Demo:** https://ice292.github.io/sales-data-dashboard/

เว็บสรุปและวิเคราะห์ข้อมูลจากไฟล์ `sales_data.csv` ซึ่งมี 10,000 คำสั่งซื้อ ช่วงปี 2024–2025 โดยคัดข้อมูลขยะออกก่อนนำมาวิเคราะห์
สร้างด้วย **React 18 + Material UI (MUI v5)** เป็นไฟล์เดียว (`index.html`) ไม่ต้อง build

## การคัดกรองข้อมูล (Data Cleaning)

ตรวจข้อมูลทุกแถวด้วยกฎ 12 ข้อ

| การตรวจ | ผล |
|---|---|
| รหัสคำสั่งซื้อซ้ำ / แถวซ้ำ | ไม่พบ |
| ยอดก่อนค่าส่ง = ราคา × จำนวน − ส่วนลด | ถูกต้องทุกแถว |
| ยอดสุทธิ = ยอดก่อนค่าส่ง + ค่าส่ง | ถูกต้องทุกแถว |
| วันที่ / เวลา | ถูกรูปแบบทุกแถว |
| จังหวัด ↔ ภาค, สินค้า ↔ หมวด, ข้อมูลลูกค้าคนเดียวกัน | สอดคล้องกันทุกแถว |
| ซื้อหน้าร้านแต่มีค่าส่ง / ซื้อออนไลน์แต่จ่ายเงินสด / ยกเลิกแต่มีรีวิว | ไม่พบ |
| **ซื้อหน้าร้านแต่จ่าย "เก็บเงินปลายทาง"** | **พบ 402 แถว → ตัดออก** |

**ผลลัพธ์:** จาก 10,000 แถว เหลือ **9,598 แถว**

ข้อมูลที่ไม่สมบูรณ์แต่ไม่ได้ลบ จัดการดังนี้

- **อายุ 15 ปี:** มีลูกค้าอายุ 15 ปี 124 คน แต่อายุ 16 ปีมีแค่ 32 คน แสดงว่าอายุถูกปัดขึ้นเป็น 15 จึงแสดงกลุ่มนี้เป็น "≤15"
- **เพศ "ไม่ระบุ":** แยกเป็นอีกกลุ่ม ไม่เดาแทน
- **คะแนนรีวิวที่ว่าง:** ไม่นำมาคิดค่าเฉลี่ย และไม่นับเป็น 0 คะแนน
- **ยอดขาย:** นับเฉพาะคำสั่งซื้อที่มีสถานะ "สำเร็จ"
- **ลูกค้า C01905:** ซื้อ 344 ครั้ง มากกว่าอันดับ 2 ถึง 2.3 เท่า จึงทำเครื่องหมายว่าผิดปกติไว้

## จุดขยะรายช่อง (Cell-level)

นับเป็น "ช่องข้อมูล" ไม่ใช่แถว ไฟล์ดิบมี 10,000 แถว × 21 คอลัมน์ = 210,000 ช่อง พบช่องขยะ **2,707 ช่อง (1.29%)** อยู่ใน 2,487 แถว

| # | จุดที่เป็นขยะ | คอลัมน์ | จำนวนช่อง |
|---|---|---|---|
| 1 | ซื้อหน้าร้านแต่จ่าย "เก็บเงินปลายทาง" (ขัดกันเอง) | วิธีชำระเงิน | 402 |
| 2 | เพศ "ไม่ระบุ" | เพศ | 197 |
| 3 | อายุ 15 ปี (น่าจะถูกปัด) | อายุ | 674 |
| 4 | คะแนนรีวิวว่าง (ไม่นับคำสั่งซื้อที่ยกเลิก 471 ช่อง) | คะแนนรีวิว | 1,434 |
| | **รวม** | | **2,707** |

หน้าเว็บแสดงข้อมูลของแต่ละจุด ดังนี้

- จำนวนช่องที่พบในแต่ละเดือน
- ช่องทางการขาย, สถานะคำสั่งซื้อ, ภาค, หมวดสินค้า และ 10 จังหวัดที่พบมากที่สุด
- ลูกค้าที่มีช่องผิดปกติมากที่สุด
- หลักฐานของแต่ละจุด เช่น กราฟจำนวนลูกค้าตามอายุที่เห็นยอดพุ่งผิดปกติที่อายุ 15 และอัตรารีวิวว่างแยกตามสถานะ
- ตารางไขว้ว่าแต่ละจุดเกิดร่วมกันในแถวเดียวกันกี่แถว
- ความสมบูรณ์ของทั้ง 21 คอลัมน์
- รายการช่องขยะครบทั้ง 2,707 ช่อง ค้นหาและกรองได้ และดาวน์โหลดเป็น CSV ได้

## ไฟล์

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | หน้าเว็บรายงาน |
| `data/summary.js` | ตัวเลขสรุปที่คำนวณไว้ล่วงหน้า (แยกตามปี: ทั้งหมด / 2024 / 2025) |
| `data/junk.js` | รายละเอียดจุดขยะรายช่องทั้ง 2,707 ช่อง |
| `data/sales_clean.csv` | ข้อมูลที่คัดกรองแล้ว 9,598 แถว |
| `data/removed_rows.csv` | 402 แถวที่ตัดออก พร้อมเหตุผล |

## เนื้อหาในรายงาน

- ภาพรวม ได้แก่ ยอดขาย, จำนวนคำสั่งซื้อ, ยอดเฉลี่ยต่อบิล, จำนวนลูกค้า, คะแนนรีวิว และอัตรายกเลิก/คืนสินค้า
- ยอดขายรายเดือนของปี 2024 เทียบกับ 2025
- สินค้า แยกตามหมวดสินค้า, สินค้าขายดี 10 อันดับ และส่วนลด
- ช่องทางการขาย, วิธีชำระเงิน, ภาค และ 10 จังหวัดที่ขายได้มากที่สุด
- ลูกค้า แยกตามช่วงอายุ เพศ และลูกค้า 10 อันดับแรก
- ช่วงเวลาที่สั่งซื้อ แยกตามชั่วโมงและวันในสัปดาห์
- คะแนนรีวิว และจำนวนวันจัดส่งเฉลี่ยของแต่ละภาค

เลือกปีได้จากแถบด้านบน (ทั้งหมด / 2024 / 2025) และกดปุ่ม "ตาราง" บนกราฟแต่ละอันเพื่อดูตัวเลขเป็นตาราง
